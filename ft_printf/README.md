# Description
This project is one of the three projects in Milestone 1 of the 42 Codam Core Curriculum. It aims to recreate the functionality of the standard `printf()` function, focusing specifically on string parsing, argument retrieval, and number conversion.

# Instruction
## Compilation
Run `make` to compile the source files and generate the static library.

Run `make fclean` to remove all compiled files, including the generated library.

Run `make re` to remove all compiled files and rebuild the library from scratch.

## Using the Library
After running `make`, a static library named `libftprintf.a` will be generated.

To use the library, include the `ft_printf.h` header in your C source file and link `libftprintf.a` during compilation.
